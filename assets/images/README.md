# Hero background photography

`index.html` expects three photos here (any real photography works — these
are just the filenames referenced from `assets/css/style.css`):

- `tenav-bg.jpg`
- `tensignage-bg.jpg`
- `tenunify-bg.jpg`

Until a file is added, its card falls back to a brand-colored gradient, so
the homepage still looks complete with none of these present.

Drop matching JPG/WebP files in with these exact names (or update the
`background-image` rules in `assets/css/style.css` if you rename them) and
they'll be picked up automatically — no other changes needed.
